# Puidutöö sõnad — Словарь технологии (работы по дереву)

Учебный материал для 5 класса эстонско-русской школы: 67 терминов по деревообработке
(эстонский ⇄ русский), с картинками, интерактивным тренажёром и Anki-колодой.

## Что внутри

| Артефакт | Файл | Описание |
|---|---|---|
| Данные (единый источник) | `data/terms.json` | 67 терминов, 4 категории, эст/рус, поисковые запросы |
| Манифест картинок | `data/images.json` | локальный файл + лицензия + автор для каждого термина |
| Картинки | `assets/images/` | 60 фото (Wikimedia Commons, свободные лицензии) + 7 сгенерированных схем |
| **HTML-тренажёр** | `docs/index.html` | один самодостаточный файл (картинки в base64), работает оффлайн |
| **Anki-колода** | `dist/puidutoo_sonad.apkg` | 134 карточки (эст→рус и рус→эст), с картинками |

## Как пользоваться (для ребёнка)

### HTML-тренажёр
Откройте `docs/index.html` в любом браузере **без интернета** — на компьютере,
планшете или телефоне (Android). Три режима:

- **📖 Учи** — смотри картинку, эстонское и русское слово; 🔊 озвучивает по-эстонски.
- **🔁 Повтори** — сначала вспомни перевод сам, потом нажми «Показать перевод».
- **🎯 Викторина** — выбери правильный перевод из четырёх, счёт ✅/❌.

Есть фильтр по разделам (древесные материалы / инструменты / черчение / операции)
и кнопка «Перемешать».

### Anki-колода
Импортируйте `dist/puidutoo_sonad.apkg` в AnkiDroid (Android) или Anki (ПК).
Прямое (эст→рус) и обратное (рус→эст) запоминание с интервальным повторением.

## Сборка (воспроизводимость)

```bash
python3 scripts/fetch_images.py     # скачать фото с Wikimedia Commons
python3 scripts/generate_diagrams.py # сгенерировать 7 схем
python3 scripts/finalize_images.py  # собрать финальный набор + data/images.json
python3 scripts/build_html.py       # -> docs/index.html
python3 scripts/build_anki.py       # -> dist/puidutoo_sonad.apkg (нужен genanki)
```

## Лицензии изображений

Фото — Wikimedia Commons, свободные лицензии (CC0, CC BY, CC BY-SA, Public Domain).
Полные данные (автор, лицензия) — в `data/images.json`. Схемы размеров/видов — собственные (CC0).

## Публикация на GitHub Pages

Репозиторий уже структурирован для публикации. Достаточно:
1. Загрузить папку проекта в GitHub-репозиторий.
2. `Settings → Pages → Source → Deploy from a branch → Branch: main, Folder: /docs`.
3. Сайт откроется по ссылке `https://<user>.github.io/<repo>/`.
